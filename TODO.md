# BIEM Cotiza — Entregables

- [x] **Flujo comercial prioritario.** El usuario puede entrar, crear una cotización, añadir ítems desde el catálogo o mediante registro manual rápido, generar el documento y compartirlo sin registrar previamente un cliente ni organizar el negocio.
- [x] **Cotizaciones flexibles.** Una propuesta admite productos y servicios mezclados, cantidades, descuentos, impuestos, cliente opcional, subtotales y total; permite editar, duplicar, exportar PDF y compartir.
- [x] **Seguimiento operativo.** Mis cotizaciones conserva el historial y permite filtrar por estado y fecha, editar, duplicar y actualizar manualmente entre Borrador, Enviada, Aprobada, Rechazada, Completada y Cancelada, distinguiendo la aprobación de la entrega realizada.
- [x] **Espacio de trabajo claro.** Inicio presenta cotizaciones generadas, pendientes, aprobadas, completadas, clientes y valor en seguimiento; la interfaz móvil usa una jerarquía clara, botones visibles y ayudas contextuales.
- [x] **Organización opcional.** Clientes, productos/servicios y configuración son herramientas de apoyo: se pueden gestionar después de resolver una cotización, no son requisitos para iniciar.
